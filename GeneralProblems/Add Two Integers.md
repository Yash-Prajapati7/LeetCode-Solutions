Leetcode Question : [Add Two Integers](https://leetcode.com/problems/add-two-integers/)

### Java

```java
class Solution {
    public int sum(int num1, int num2) {
        return num1 + num2;
    }
}
```

### C++

```cpp
using namespace std;

class Solution {
public:
    int sum(int num1, int num2) {
        return num1 + num2;
    }
};
```
